SECURITY AUDIT
Issues a code review would miss — found in trigger logic
● CRITICAL
Hardcoded Manager Credentials
Password "ADMIN123" is embedded plaintext in a WHEN-BUTTON-PRESSED trigger inside the compiled .fmb binary. Any developer who opens Forms Builder extracts it immediately.
FIX → Replace entirely with APEX workspace authentication. Apply MANAGER role authorization scheme to approval page. Do not move this credential to PL/SQL — that's not an improvement.
● HIGH
Plaintext Password Storage
Customer passwords stored as VARCHAR2(10) plaintext in GRP1_REGISTEREDINFO.password11. Any DBA or unrestricted SELECT exposes all credentials.
FIX → APEX_UTIL.GET_HASH before storage, or use APEX End User Account management (handles hashing natively).
● MEDIUM
Universal Default Password
Every approved account is inserted with password11 = '0000'. All new customers share the same initial credential until they manually self-register online.
FIX → Generate random temporary password on approval. Email to customer. Enforce password change on first login.
